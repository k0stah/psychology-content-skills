# Contributing

Keep one skill focused on one editorial job. Explain the trigger in its `description`, specify the inputs and usable output, and document what to do when evidence or tools are missing.

Use English for portable instructions and the requested language for generated content. Add Ukrainian examples where they clarify the workflow. Keep all examples synthetic and label them accordingly.

When adapting another project, record its exact reviewed commit, file paths, license and our changes in `sources/upstream.json`. Preserve applicable notices. Never silently overwrite our adapted skills with the latest upstream copy.

Run `python scripts/validate.py` before proposing a change. Add a focused evaluation case for a meaningful behavior change; report observed results separately from expectations. Do not claim that a connector, model or publishing flow works without testing it.

Do not submit client records, real group transcripts, credentials, private author profiles or private analytics in issues or pull requests. Use the minimum synthetic example needed to explain a problem.

Human authors retain the final professional and publication decision. Improvements must preserve the author's thesis, distinguish evidence from inference and avoid invented commercial or clinical outcomes.
