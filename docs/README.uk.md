# Psychology Content Skills — українською

Відкрита збірка навичок для авторського блогу з психології та психотерапії. Вона допомагає перетворювати власні думки на сценарії й дописи, зберігати голос авторки, перевіряти зміст і враховувати фактичні звернення на консультації.

## Сім навичок

- `psychology-blog` — головний редактор і координатор.
- `author-context` — спільний контекст авторки, її послуг, стилю та професійних меж.
- `audience-funnel` — аудиторія й три задачі контенту: знайомство, довіра, звернення.
- `format-research` — дослідження доступних відеоформатів із джерелами.
- `content-repurpose` — різні ракурси однієї теми та матеріали, які можна записати.
- `psychology-review` — перевірка позиції авторки, тверджень, конфіденційності й закликів.
- `content-measurement` — аналіз звернень, записів, оплат і часу на підготовку.

Ці ролі можна виконувати послідовно в одному агенті. Для користувачки це один помічник; створювати сім окремих чатів не потрібно.

## Початок роботи

Для середовища, яке підтримує Agent Skills, у збірці передбачене встановлення через [Skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add k0stah/psychology-content-skills
```

У меню оберіть середовище та потрібні навички. Для повного процесу потрібні координатор і спеціалізовані навички. Окрему навичку також можна використовувати самостійно.

Інший спосіб: відкрити клон репозиторію в агенті й попросити його прочитати `skills/psychology-blog/SKILL.md`. Це використання файлів у проєкті, без автоматичного встановлення навичок у ChatGPT.

Перший запит:

> Використай $author-context. Допоможи описати мої послуги, підхід і авторський голос. Усе, чого ми ще не знаємо, познач як невідоме.

Наступний запит:

> Використай $psychology-blog. Ось моя думка: [нотатка]. Запропонуй різні ракурси для знайомства, довіри та звернення, потім підготуй три короткі відео українською для мого погодження.

## Де зберігається особистий контекст

Спільний файл — `private/psychology-content/context.md` у робочому проєкті. Шаблон входить до `author-context`. У цьому ж приватному каталозі можна зберігати чернетки, правки, референси та результати публікацій.

Цей репозиторій ігнорує каталог `private/` у Git. Якщо навички використовуються в іншому репозиторії, спочатку потрібно виключити відповідний приватний шлях із Git або обрати каталог поза репозиторієм. Для відповіді лише в чаті створення файлів не потрібне.

До публічної збірки входять лише інструкції, шаблони й вигадані приклади. Власні інсайти з практики слід подавати узагальнено, без упізнаваних подробиць людей.

## Що вже передбачено

Спочатку агент зберігає думку авторки, потім визначає задачу матеріалу, пропонує різні ракурси, пише сценарії й перевіряє їх окремим кроком. Авторка погоджує конкретну версію та публікує її. Статистику і джерела звернень можна вносити вручну.

Пошук і аналіз відео залежать від інструментів та доступів середовища. Збірка не містить налаштованого скрапера, платних ключів чи автоматичної публікації. Недоступний ролик або невідомий результат позначається як обмеження.
